ABOUT THE PROJECT

Technology with a purpose.

MindMetric is an educational machine learning project that explores the relationship between students' digital habits, academic routines and lifestyle factors.

Its prediction is based on a trained regression model. It should not be used to diagnose, treat or make decisions about anyone's mental health.
